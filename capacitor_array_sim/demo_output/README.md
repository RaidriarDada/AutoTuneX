## KEMET CER ENG KIT 28 variant

The kit's C0G/NP0 parts cover only six values: 10, 22, 120, 180, 270 and
1000 pF (100–200 pieces of each). Everything else in the kit is X7R or X5R and
must not be used for RF tuning.

`python capacitor_array_sim/demo_3x3_kit.py --series kit` re-fits the twelve
positions from those six values with at most three parts in parallel:

| File | What it is |
| --- | --- |
| `capacitors_kit.csv` | Per-position kit parts (≤ 3 in parallel) |
| `usage_kit.csv` | How many of each kit value the design uses (27 parts total) |
| `lookup_kit.csv` | The same 60-state lookup table, regenerated for the kit values |
| `array_3x3_kit.png` | All 60 states with the kit values |

The kit fit keeps 48 of 60 states in band, the same as the free-value optimum,
with 27 capacitors from a single kit SKU.

## Control word: 20 bits

`C1`–`C12` are the mesh switches, `E1`–`E8` are the end (return) switches.
Every row has **exactly one** `E` bit set: the node that is connected to the
ground plane. The other seven end switches are open and are modelled as a
0.1 pF shunt each.

`hex_word` uses `C1 = bit 0` … `C12 = bit 11`, `E1 = bit 12` … `E8 = bit 19`.

### Mesh switches (capacitor between two nodes)

| Bit | Edge | Bit | Edge |
| --- | --- | --- | --- |
| C1 | (0,0)–(1,0) | C7 | (1,0)–(1,1) |
| C2 | (0,0)–(0,1) | C8 | (1,1)–(2,1) |
| C3 | (0,1)–(1,1) | C9 | (1,1)–(1,2) |
| C4 | (0,1)–(0,2) | C10 | (1,2)–(2,2) |
| C5 | (0,2)–(1,2) | C11 | (2,0)–(2,1) |
| C6 | (1,0)–(2,0) | C12 | (2,1)–(2,2) |

`capacitors.csv` repeats the same mapping per row in `from_node` / `to_node`.

### End switches (node to ground)

`E1` = node (0,1), `E2` = (0,2), `E3` = (1,0), `E4` = (1,1), `E5` = (1,2),
`E6` = (2,0), `E7` = (2,1), `E8` = (2,2). That is node index `3·row + column`
for every node except the source (0,0).

Driving them from eight GPIOs is the simplest option. A 3-to-8 one-hot decoder
also works: the LUT already stores the one-hot pattern, so firmware just needs
to map `E1..E8` to the decoder inputs.

## Part numbers

`PPI-GMC10-161` is a Passive Plus GMC series C0G capacitor in the 0603 case
(`GMC10`), value code `161` = 16 × 10^1 = **160 pF**. Parts from 1 nF up use
the 2225 case (`GMC57`), for example `PPI-GMC57-182` = 18 × 10^2 = **1800 pF**.
Values below 10 pF use `R` for the decimal point, for example `4R7` = 4.7 pF.

Each position is one to three of these parts in parallel; `nominal_pf` is their
sum and `error_pf` is the difference from the optimised target.
